# Methodology

A work product follows the video's timeline. Each candidate reference includes the spoken wording, timestamp, identified person/event/work, confidence from 0 to 1, an original source link, context, and a short significance synopsis.

## Honest uncertainty

A plausible reference is still a hypothesis until the source is checked. Low-confidence candidates remain visible with a disclaimer rather than being silently discarded. A YouTube URL may have no accessible captions; that is reported as an unavailable input.

## Images

Thumbnails are explanatory, not evidence. An archival image, attributed source image, or generated reconstruction may be used case by case. Reconstructions are labeled clearly so a cinematic illustration is never mistaken for historical footage.

Transcript API integration and a transcript copy/paste field are deferred. See `.hermes/NEXT_STEPS.md` in the project repository.
