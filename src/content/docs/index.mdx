## What the work product contains

<CardGrid stagger>
  <Card title="Timeline first" icon="magnifying-glass">
    References appear in the order they were spoken, with timestamps and a visual overview.
  </Card>
  <Card title="Evidence, not vibes" icon="document">
    Every candidate carries a confidence score, source URL, context, and an uncertainty note when needed.
  </Card>
  <Card title="Images with a point" icon="image">
    Use archival material when it helps; use an explicitly labeled reconstruction when imagination explains the history better.
  </Card>
</CardGrid>

> **Scope note:** A YouTube URL alone does not guarantee an accessible transcript. The future agent will report private, captionless, or unavailable videos honestly.
